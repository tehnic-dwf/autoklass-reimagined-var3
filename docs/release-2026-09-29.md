# V3: update dupa feedbackul din call

Aceasta nota descrie versiunea finala din 29 septembrie. Notele de review anterioare pastreaza iteratiile intermediare; unde difera, descrierea de mai jos reflecta implementarea curenta.

## Homepage si meniu

- Oferte vanzari si oferte service in sectiuni dedicate, cu acces vizibil si din meniu.
- Ofertele auto sunt mai sus in pagina, inaintea zonei de marci. Campania SUV are modelele participante langa denumirile lor; masinile cu pret redus sunt intr-un carusel separat, cu badge Oferta.
- Meniul mobil este mai compact, cu linkurile unul sub altul.
- Zona de caroserii foloseste ilustratii originale, cu forme inspirate din mai multe marci Autoklass. O sectiune separata propune selectii pentru oras, familie, drumuri lungi si electric, cu filtrele si numarul rezultatelor vizibile.

## Marci si autovehicule rulate

- Sectiunea Centru autorizat de vanzari este separata de Autovehicule rulate.
- Sigle aliniate, trei pe rand; Ford apare cu logo-ul furnizat si mentiunea In curand.
- Acces separat la rulate Autoklass, toate marcile, si Das WeltAuto Ploiesti / Brasov.

## Cautare si listing

- Ordinea criteriilor principale este buget, stare, marca, model. Marcile si modelele se adapteaza la nou/rulat.
- Oras in filtrele avansate, in loc de denumirea interna Sucursala.
- Cardurile includ putere, cilindree, emisii CO2 si tractiune, alaturi de celelalte specificatii. Denumirile tractiunii sunt explicite.

## Pagina masinii

- Datele tehnice raman deasupra fotografiilor, conform formatului aprobat.
- Galerie libera de controale suprapuse; navigarea, marirea si salvarea sunt intr-o bara compacta sub imagine.
- Pretul final, pretul anterior si economia sunt grupate clar. O singura prezentare de leasing, cu rata lunara vizibila si conditiile expandabile.
- Solicitarea de oferta are buton albastru; consultantul si locatia sunt grupate sub acesta.
- Sectiuni mai compacte si mai putine informatii repetitive.
- Dotari organizate pe categorii si subgrupe tematice. Fiecare dotare afiseaza Standard sau Optional inclus, intr-o coloana aliniata.

## Programare service

- VIN obligatoriu, la inceputul formularului; kilometraj optional.
- Exemplu de identificare dupa VIN si selectie marca/model din liste, cu completare manuala daca VIN-ul nu este recunoscut.
- Tarifele afisate tin cont de model si de sucursala selectata.

## Limitele prototipului

- Identificarea VIN foloseste date locale demonstrative, fara API de productie.
- Clasificarea dotarilor si o parte din valorile tehnice completate sunt exemple de prototip, conform instructiunilor primite; necesita validare cu datele Autoklass.
- Diferenta comerciala dintre In stoc si Livrare imediata ramane de confirmat cu clientul. Nu s-au inventat termene de livrare.
- Campania SUV nu confirma automat eligibilitatea fiecarui VIN din caruselul de reduceri.
- Noile marci asiatice asteapta denumiri confirmate.

Ilustratiile si prompturile sunt documentate in home-discovery-2026-09-29.md. Verificarile pe mobil sunt documentate in review-urile aferente.
